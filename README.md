# cost-of-college

Public-data tools for answering a concrete question: **can this student, in this family, actually afford to attend this college?**

The project separates sticker price, grants, scholarships, loans, work-study, expected family resources, and money actually available to the student.

The first analytic layer is a $5,000 household-income grid. The second is a set of reproducible hypothetical families built from public occupational earnings and tax-rule data.
